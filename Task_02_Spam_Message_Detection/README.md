# Task 02 - Spam Message Detection

## Objective
To develop a machine learning model that detects whether a message is spam or not spam.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Naive Bayes

## Features
- Detects spam messages
- Detects normal messages
- Displays model accuracy
- Allows user to test new messages

## How to Run
1. Open the project in VS Code.
2. Install required libraries.
3. Run `spam_detector.py`.
4. Enter a message in the terminal.

## Sample
Input: Congratulations! You won a free prize  
Output: Prediction: spam

Input: Can we meet tomorrow?  
Output: Prediction: not spam
