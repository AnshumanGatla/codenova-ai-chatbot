# Task 03 - Movie Recommendation System

## Objective
To develop a simple movie recommendation system that recommends movies based on similar genres.

## Technology Used
- Python

## Features
- Stores movie and genre information
- Takes a movie name from the user
- Finds movies with similar genres
- Displays recommended movies

## How to Run
1. Open the project in VS Code.
2. Run `movie_recommendation.py`.
3. Enter a movie name.
4. View the recommended movies.

## Sample Output

Input:
Inception

Output:
- Interstellar
- The Dark Knight
- Avengers
