# AI Chatbot

## Objective
To develop a simple AI chatbot that responds to user messages using predefined text matching.

## Technologies Used
- Python

## Features
- Greeting responses
- Answers basic questions
- Help response
- Handles unknown messages
- Exit command

## How to Run
1. Open the project in VS Code.
2. Run chatbot.py.
3. Enter messages in the terminal.

## Sample Interaction
User: hello
Bot: Hello! How can I help you?

User: what is your name
Bot: I am CodeNova AI Chatbot.

User: bye
Bot: Goodbye!
